The npm website returned 403 for several package pages; research used npm registry metadata and the published Toolkit artifact instead. Domo's official YAML was downloaded for inspection; external specifications are kept outside the publishable artifact. All package and contract decisions are documented in the matrix and lockfile.

The current official [AppDB reference](https://www.domo.com/docs/portal/API-Reference/app-framework-apis/AppDB-API), [framework YAML](https://www.domo.com/docs/openapi/framework/appdb.yaml), [Product API reference](https://www.domo.com/docs/portal/API-Reference/Product-APIs/App-DB), [manifest guide](https://www.domo.com/docs/portal/Apps/App-Framework/Guides/manifest), and [querying-data guide](https://www.domo.com/docs/portal/Apps/App-Framework/Guides/querying-data) were inspected. Dataset aliases are separate from Platform dataset endpoints. App Framework and Product AppDB use different base paths and authentication contexts. No real Domo credentials were loaded or requests made to a Domo instance.

Dependency audit initially found an advisory in fast-glob's transitive braces dependency. Fixed-path discovery made that dependency unnecessary, so it was removed. A development esbuild override selects the patched >=0.28.1 release; the build is verified with it. npm audit returned zero advisories after these changes. Rerun audit before publication; an audit is not a complete security review.
