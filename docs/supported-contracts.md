# Contract compatibility matrix

Reviewed 14 October 2026. Reference tests are independent local cases transcribed from official contracts, not recordings of live requests. This matrix describes simulator fidelity, not a Domo certification.

Let `D = /domo/datastores/{version}/collections/{name}/documents`.

| Family/version                                                               | Method and endpoint                  | Body                            | Success                         | Fidelity / omissions                                                                | Official reference                                                                                     |
| ---------------------------------------------------------------------------- | ------------------------------------ | ------------------------------- | ------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| App Framework dataset v1                                                     | GET `/data/v1/{alias}`               | None                            | 200 JSON row array              | Source-to-alias mapping, fields/offset/limit only; other query features rejected    | [Data specification](https://www.domo.com/docs/openapi/framework/data.yaml)                            |
| AppDB v2                                                                     | POST `D`                             | `{content: object}`             | 200 document                    | Stateful create, deterministic subset of metadata; no permissions/sync              | [Create](https://www.domo.com/docs/api-reference/appdb-api/create-document)                            |
| AppDB v2                                                                     | GET `D`                              | None                            | 200 document array              | `limit` and `offset`; insertion order approximation                                 | [List](https://www.domo.com/docs/api-reference/appdb-api/list-documents)                               |
| AppDB v2                                                                     | GET `D/{id}`                         | None                            | 200 document                    | Missing document/collection -> synthetic 404                                        | [Get](https://www.domo.com/docs/api-reference/appdb-api/get-document)                                  |
| AppDB v2                                                                     | PUT `D/{id}`                         | `{content: object}`             | 200 document                    | Entire content replaced, immutable metadata                                         | [Replace](https://www.domo.com/docs/api-reference/appdb-api/replace-document)                          |
| AppDB v2                                                                     | DELETE `D/{id}`                      | None                            | 200 empty body                  | Missing document -> synthetic 404                                                   | [Delete](https://www.domo.com/docs/api-reference/appdb-api/delete-document)                            |
| AppDB v2                                                                     | POST `D/query`                       | Filter object directly          | 200 document array              | Explicit scalar/object equality and operator subset; query parameters rejected      | [Query](https://www.domo.com/docs/api-reference/appdb-api/query-documents)                             |
| AppDB v2                                                                     | PUT `D/update`                       | `{query, operation}`            | 200 integer                     | `$set/$unset/$inc` on content paths, all matched documents; no upsert               | [Partial update](https://www.domo.com/docs/api-reference/appdb-api/partially-update-documents)         |
| AppDB v1 (explicit opt-in)                                                   | POST `D`; GET `D`                    | Same documented bodies as above | 200 document / array            | Separate numeric `owner/createdBy/updatedBy` adapter                                | [Official YAML v1 sections](https://www.domo.com/docs/openapi/framework/appdb.yaml)                    |
| AppDB v1 (explicit opt-in)                                                   | GET/PUT/DELETE `D/{id}`              | None / `{content}` / none       | 200 document / document / empty | Same scoped CRUD behavior; no translation to a v2 URL                               | [Official YAML](https://www.domo.com/docs/openapi/framework/appdb.yaml)                                |
| AppDB v1 (explicit opt-in)                                                   | POST `D/query`; PUT `D/update`       | Filter / `{query, operation}`   | 200 array / integer             | Same explicit query/update subset; legacy entries are `x-excluded` in rendered docs | [Official YAML](https://www.domo.com/docs/openapi/framework/appdb.yaml)                                |
| Product AppDB                                                                | Any `/api/datastores/*`              | Unsupported                     | Blocked                         | Different auth/datastore contracts; never translated                                | [Product API](https://www.domo.com/docs/portal/API-Reference/Product-APIs/App-DB)                      |
| Platform OAuth dataset API                                                   | Any public platform dataset endpoint | Unsupported                     | Blocked                         | Not the App Framework alias API                                                     | [Platform specification](https://www.domo.com/docs/openapi/platform/dataset.yaml)                      |
| SQL, bulk, collection management, permissions, workflows, Code Engine, users | Any                                  | Unsupported                     | Blocked                         | Not silently accepted                                                               | [App Framework reference](https://www.domo.com/docs/portal/API-Reference/app-framework-apis/AppDB-API) |

All unsupported paths/methods/versions yield synthetic 501 responses and are tracked as violations. The Vitest helper fails a test for any such violation. Synthetic malformed-body/query/update errors use 400; payload limits use 413; configured auth faults use their explicit status. Error text is an approximation; `toe` identifies it as test-generated. HTTP codes and supported request/response shapes are grounded in documentation.

Supported query operators: equality, `$eq/$ne/$gt/$gte/$lt/$lte/$in/$nin/$and/$or/$exists`, dotted object fields. Array equality and scalar membership are supported, but array traversal, date/BSON coercion, regex, expression evaluation, geo operators, aggregation, sort and MongoDB edge cases are unimplemented. System timestamps are JSON strings, not BSON dates. Unknown operators are rejected even against empty collections.

Modern manifest fields use [Domo's manifest documentation](https://www.domo.com/docs/portal/Apps/App-Framework/Guides/manifest). The current [AppDB guide](https://www.domo.com/docs/portal/API-Reference/app-framework-apis/AppDB-API) also shows `collectionsMapping`; this requires the explicit adapter. The legacy `mapping` dataset adapter accepts the modern entry shape only; older alternative entry shapes are unverified and rejected.
